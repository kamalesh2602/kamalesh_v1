# Kamalesh G - Portfolio

A personal portfolio website built using React, TypeScript, Vite, and Tailwind CSS.

Designed with a glassmorphism-inspired interface to showcase projects, technical skills, and professional experience in a clean and modern way.

### Highlights

* Project showcase with dedicated project detail pages
* Centralized data management using TypeScript
* Resume viewing and download support
* Responsive design
* React Router based navigation

### Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* React Router DOM
